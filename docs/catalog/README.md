# Historical source-discovery index — batch A

Indexed **389 distinct named Rydberg-related records** after scanning 900 Library entries in 9 pages. This is a metadata inventory, **not a repository file manifest**. Names identify candidate original source records, not proof of solver completion, hardware purchases, or scientific publication.

**[CSV of source names and dates](HISTORICAL_SOURCE_INDEX_BATCH_A.csv)**. Dates are Library record dates, not experiment dates. Overlapping ZIPs and manuscript revisions are intentionally indexed for provenance, but should be deduplicated before ingestion. Generic names such as `logs.zip` may not be identified by filename alone.

The repository's existing 290 files are enumerated separately in [the asset register](../traceability/ASSET_REGISTER.csv). **Import status in this index is discovery-only** until the actual file is placed in Git and registered with a checksum.

Additional older batches are documented in subsequent history/import work. See the [research chronology](../research/RESEARCH_CHRONOLOGY.md), [simulation evidence](../results/EVIDENCE_INDEX.md) and [evidence policy](../operations/RELEASE_POLICY.md).
