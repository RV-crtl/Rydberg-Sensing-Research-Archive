# Claims, evidence and scope

The authoritative machine-readable ledger is [`CLAIM_EVIDENCE.csv`](CLAIM_EVIDENCE.csv). Every headline number must have an immutable input, figure or primary document source and a clearly stated modality.

- **Measured:** laboratory/VNA/optical experiments with documented conditions.
- **Simulated:** native HFSS complex fields and numerical results; the solver model is the relevant truth context.
- **Derived:** mathematical transformations/optimisation of recorded simulated fields, sometimes with additional assumptions.
- **Published:** independently verifiable external publication records (rather than manuscript drafts).

Before changing README values, update the claim ledger, figure source and engineering interpretation together. Do not describe simulated RF state selectivity as experimentally calibrated rubidium full-Stokes performance.
