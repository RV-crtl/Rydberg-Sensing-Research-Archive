## Assessment integrity

These materials are deliberately mapped to the **HD descriptor** for each criterion, but the existence of a page is not proof that an external student can operate every physical instrument. That requires actual laboratory access, owner-approved safety SOPs, remaining primary files and live handover. The [asset register](ASSET_REGISTER.csv), [source completeness section](../handover/HANDOVER.md) and automated checks make that distinction inspectable.
