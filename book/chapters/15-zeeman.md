# Zeeman bias, sublevel structure and failure modes

**Part:** Atomic physics · **Type:** educational background, not new experimental data.

## Core explanation

A weak magnetic field shifts magnetic-sublevel energies approximately by ΔE≈μB gJ mJ B in a simple fine-structure linear regime. Ground-state hyperfine regimes can require Breit–Rabi treatment and excited-state mixing may invalidate a naive linear formula. The project tested a bias-coil path but did not establish a reliable full-vector atomic readout from it; that historical direction should remain separate from the later metasurface analyser. The location and orientation of the quantisation axis matter as much as B magnitude.

## Worked learning / laboratory exercise

Record field map, coil polarity, instrument calibration, source-frequency stability and laser spectra with B=0 and RF off. Predict an approximate linear shift using a declared gJ, mJ and B, and then compare against a full ARC/RydIQule state model with consistent units.

## Self-test

**Question:** If applying current changes an optical peak but also moves the laser lock, what can be concluded?

<details><summary>Reveal answer and scientific reasoning</summary>

Very little about a Zeeman-origin response until laser lock drift, coil heating, RF field coupling and background have been independently controlled.

</details>

## Red flags and diagnosis

Claiming a source-frequency feature as a magnetic sublevel because it appeared near the predicted region.

## Validity and reflection

- Identify each approximation or model limitation before reusing the worked example.
- Identify which physical measurement or native HFSS field could falsify the argument.
- Document units, state basis, time convention, calibration reference, exact code and source versions.
- Check sensitivity to numerical errors and state a quantitative acceptance gate before declaring a result.
