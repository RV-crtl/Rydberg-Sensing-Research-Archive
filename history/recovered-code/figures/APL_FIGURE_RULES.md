# Figure conventions used in v90

The data graphics follow AIP/APL-style publication conventions, scaled up for poster viewing:

- Experimental measurements are plotted as explicit symbols.
- Smooth curves through sparse experimental measurements are labelled as guides to the eye, not physical models.
- Simulations use continuous/dashed line styles and are explicitly labelled SIMULATION in the poster text.
- Analytic results are explicitly labelled ANALYTIC.
- Model heatmaps are explicitly labelled MODEL and are not presented as fitted experimental data.
- Multi-panel graphics use (a), (b) labels.
- Legends are outside the data region whenever possible.
- Curves differ by both colour and line/marker style so interpretation does not depend only on colour.
- Figure lettering and lines are consistent and comfortably above AIP's minimum published-size guidance.
- Vector PDF assets are used for the main plots so axes, labels and curves remain sharp at A1 size.
