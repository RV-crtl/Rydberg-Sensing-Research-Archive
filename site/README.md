# Research microsite

`index.html` is a portable, responsive, dependency-free static research microsite (CSS, JS and images local). Open it directly in a browser or deploy `site/` to any static hosting service. The images are source-matched exports from the actual manuscript's figures and project poster. Links assume the complete repository file tree exists, so for GitHub Pages prefer publishing the entire repository root with GitHub Pages or adapting relative links when deploying `site/` alone.

The site links to the full text evidence trail; numeric claims are not generated client-side. No external analytics or data transmission is embedded.
